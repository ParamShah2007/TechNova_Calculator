## 📖 About The Project

**Calculator Web App** is a modern calculator project created using pure **HTML5**, **CSS3**, and **Vanilla JavaScript**.

The project demonstrates:

* Semantic HTML structure
* Responsive CSS Grid layout
* Modern dark-themed user interface
* Interactive button effects
* Keyboard input handling
* Clean and maintainable JavaScript logic

This project is ideal for:

* 🎓 Front-end development practice
* 💼 Portfolio projects
* 🧑‍💻 JavaScript learning
* 📱 Responsive web design practice
* 🚀 Beginner-friendly web application development

# 📋 Main Functions

### JavaScript Functions

| Function            | Purpose                                      |
| ------------------- | -------------------------------------------- |
| `inputNumber()`     | Handles number input                         |
| `inputDecimal()`    | Adds decimal points                          |
| `chooseOperator()`  | Selects arithmetic operators                 |
| `calculate()`       | Performs calculations                        |
| `equals()`          | Displays the final result                    |
| `clearCalculator()` | Resets the calculator                        |
| `deleteLast()`      | Removes the last character                   |
| `percent()`         | Converts the current value into a percentage |
