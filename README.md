# Calculator Web App

A simple, modern, and responsive calculator built using **HTML**, **CSS**, and **JavaScript**. It supports basic arithmetic operations, percentage calculations, delete functionality, and keyboard input.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage calculation
- ⌫ Delete last digit
- 🧹 Clear all input
- ⌨️ Full keyboard support
- 📱 Responsive and modern UI

## 🖥️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `0-9` | Enter numbers |
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `.` | Decimal point |
| `Enter` or `=` | Calculate result |
| `Backspace` | Delete last digit |
| `Esc` or `C` | Clear calculator |
| `%` | Percentage |

## 📋 Main Functions

### JavaScript Functions

- `inputNumber()` → Handles number input
- `inputDecimal()` → Adds decimal points
- `chooseOperator()` → Selects arithmetic operators
- `calculate()` → Performs calculations
- `equals()` → Displays the result
- `clearCalculator()` → Resets the calculator
- `deleteLast()` → Removes the last character
- `percent()` → Converts the current value into a percentage
